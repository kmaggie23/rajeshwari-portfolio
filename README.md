# Rajeshwari Khobragade Portfolio

React + Vite + Tailwind portfolio website.

## Run
1. Install Node.js.
2. Open this folder in VS Code.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL shown by Vite.

## Customize
Edit `src/main.jsx` for content and `src/styles.css` for visual styling.
